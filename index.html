Synchronisation sans inscription (PC ⇄ téléphone).

📖 Première fois ? Créer ma base gratuite (3 min)
  1. Va sur console.firebase.google.com avec ton compte Google, clique « Créer un projet » (désactive Google Analytics).
  2. Menu « Build / Realtime Database » > « Créer une base de données », région Belgique, mode test.
  3. Copie l'URL affichée en haut de la page Données (https://…firebasedatabase.app).
  4. Onglet « Règles », remplace tout par le texte ci-dessous puis « Publier » :
    {"rules":{".read":false,".write":false,"decks":{"$id":{".read":true,".write":true}}}}
  5. Colle l'URL ci-dessous et clique sur « Activer ».
